# 更新日志：网页端分享模式（2026-08-19）

项目：三角洲战术地图（map-tools 0.0.2-indoor）

## 新增：分享模式（Web 独占）

- 网页端工具栏新增"分享"按钮（`美术资源/分享.svg` 图标），点击打开分享菜单。
- 首次分享需填写**战术名**；开启后生成 6 位随机后缀并自动跳转 `?share=<后缀>`，当前战术布置保留在分享模式中继续编辑。
- **主机**：分享菜单显示"主机"标识、后缀与完整链接、战术名、**访客数量与昵称列表**；对战术的每次修改 500ms 防抖实时同步给全部访客。
- **访客**：凭后缀访问，首次需填写**昵称**（localStorage 记忆，可在分享菜单修改）；只读（复用演示模式全套锁定，无编辑权限）；分享菜单显示战术名与同步信息「主机于 X 秒前修改战术，已于 Y 年M月D日 HH:mm 同步」（静态文本，不自动刷新）。
- **过期**：主机关闭标签页（pagehide sendBeacon）或停止共享，后缀即刻失效；另有 15 秒心跳超时兜底。后续访问者看到"该分享已过期"。

## 技术实现

- **中继服务器** `server/share-server.cjs`（零依赖 Node http + SSE）：房间制（后缀即房间），`host/state/beat/close/info/events` 端点；访客 SSE 连接即注册、断开即移除，访客统计实时准确；`npm run share:server` 启动，dev 走 Vite 代理 `/api/share → 8781`。
- **客户端**：`shareClient.ts`（API 封装）+ `ShareModal.tsx`（未分享/主机/访客/过期四态 + 首访昵称弹窗）+ App 主机/访客接线；访客只读通过 `demoReadOnly` 扩展（`lanVisitor demo || shareVisitor`）吃现有全部锁定。
- **Docker**：运行阶段从 nginx 改为 `node:22-alpine` 跑中继服务器（静态 + API 一体），端口 8781，compose 映射 `8080:8781`。
- GitHub Pages 为纯静态托管，分享按钮置灰并提示"需部署分享中继服务器（见 Docker 部署）"。

## 验证

- `tsc --noEmit`、`npm run build` 通过。
- 服务器冒烟：health/建房/推 state/访客注册与列表/SSE 广播/close 后 404、15s 心跳过期、SPA fallback 全部通过。
- APK 不受影响（Web 独占，安卓端无此按钮）。

## 已知边界（未验证项）

- 浏览器双端联调（主机编辑 → 访客实时跟随、昵称修改重连、过期提示）需在部署中继的环境人工验证。
- 房间为内存存储，中继重启全部失效；后缀即凭证，无额外鉴权。
