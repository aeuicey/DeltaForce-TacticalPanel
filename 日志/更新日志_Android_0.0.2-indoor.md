# 更新日志（Android 端）· 0.0.2-indoor（2026-08-19）

## 新增

- **局域网地图协作（Android 独占）**：主机一键开服（NanoHTTPD 内嵌服务器，端口 18080），访客浏览器直达战术面板；演示模式（只读跟随）/ 战术协作模式（双向同步）。
- **协作增强**：演示全权限锁定；横幅可 X 关闭为状态光条（演示橙/协作绿）；主机运行中实时切换模式并广播（访客提示"权限更改"）；同步视角（访客 flyTo 平滑跟随主机视角，主机长按按钮看说明）；移动端访客自动切换触控操作逻辑并提示；竖屏提醒。
- **开屏视频（Android 独占）**：高阶菜单入口，支持自定义 mp4（系统文件管理器选择，持久化）与"可跳过"设置；默认视频打包进 APK；解码失败警告兜底；主界面淡入过渡。
- **高阶菜单**：二级目录（地图协作、开屏视频），母按钮与其他按钮同尺寸。
- **绘图组件锁定**：锁定后防移动/编辑/擦除，选中框只留解锁按钮；套索圈选含锁定图形时整组保护并提示「存在图例处于锁定状态，请先解锁」；锁定/解锁图标取自美术资源 SVG。
- **鼠标中键拖动地图**（任意工具下可用）。

## 修复

- 选中框按钮/手柄滚轮缩放后脱离图形（zoom 实时重建）；套索包围框同款漂移。
- 视角同步按钮遮挡右侧面板（z-index 1200 → 90）。
- 访客视角同步失效（原生存 lat/lng、访客读 centerLat/centerLng 字段名不匹配）。
- 锁定/解锁图标与样式/删除按钮尺寸不一致：最终统一为按钮显式字号 + 锁定 SVG `height:1em`，与 FA 字体图标构造性同高（桌面 13px / 移动端 14px）。
- 高阶菜单内图标跟随主题色；演示横幅/光条紧贴工具栏。
- 应用版本号修正：`versionCode 2`、`versionName "0.0.2-indoor"`（安装后显示正确版本，可覆盖升级）。

## 验证

- `tsc --noEmit`、`vite build`、`cap sync`、`assembleDebug` 全部通过；aapt 核验版本号。
- 真机联测（协作双机同步、视角跟随、开屏播放）以用户环境实测为准。

## 追加（2026-08-20）：协作乱码与体验修复

- 修复 NanoHTTPD 无 charset 默认 US-ASCII 导致同步内容中文变 `?`（响应与 POST 头强制 UTF-8）。
- 视角跟随生效期间锁定访客视角操作；访客缩放钳位本机范围修复跨设备震荡。
- 原生 alert 全部替换为应用内深色主题弹窗；开屏视频默认静音 + 右上角静音切换按钮；首帧就绪前隐藏视频消除占位图标。
- 渠道定位更新：手机版（Android APK）独占局域网协作与开屏视频；纯静态版（Pages/Windows）与网页版（含分享）见 Web 日志。

## 追加（2026-08-22）：套索群组锁定与上游 v0.1.0 合并

- 合并上游 v0.1.0（干员战术道具、载具空投、指南针、分层兵棋、阶段/回合、部署备注等），fork 独占功能全部保留。
- 套索选中少于 2 个图形组时不再显示多余的锁定按钮（单独锁定走选中框既有按钮）。
- 新增「作为群组锁定」：套索命中多个未锁定图形组时显示带角标的群组锁定按钮（hover/长按显示提示）；含已单独锁定图形时点击仅提示不执行。
- 群组锁定后：组内图形不可移动/编辑/删除/擦除，点选组内单个图形自动扩展选中整个群组（Canva 式），任何修改提示「请先解除群组锁定」；解除入口为套索框上的「解除群组锁定」按钮；操作入历史栈可撤销。
- 全客户端生效（lockGroup 随状态快照同步）；复制粘贴的副本自动重映射不共享锁定组。
