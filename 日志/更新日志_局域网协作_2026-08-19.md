# 更新日志：Android 局域网协作模式（2026-08-19）

项目：三角洲战术地图（map-tools 0.0.1）

## 新增：地图协作（Android 独占）

安卓主机一键开启内嵌 Web 服务器，把当前战术布置同步到局域网：

- 顶部工具栏新增"协作"按钮（图标取自 `美术资源/地图协作.svg`），仅 Android 端显示，运行中有高亮态。
- 弹窗可选两种模式并显示访问地址 `http://<内网IP>:18080`：
  - **演示模式**：访客只读，自动跟随主机状态，顶部显示"演示模式 · 仅观看"横幅；
  - **战术协作模式**：访客拥有编辑权限，改动回传主机并同步给所有端。
- 访客用同一 Wi-Fi 下的任意浏览器打开该地址，直达与主机一致的战术面板（服务器直接托管 APK 内 Web 资源，SPA 回退到 index.html）。
- 服务器运行期间持 PARTIAL_WAKE_LOCK 防息屏断连（新增 `WAKE_LOCK` 权限）。

## 技术实现

- **原生插件** `LanServerPlugin`（项目首个自定义 Capacitor 插件，NanoHTTPD 2.3.1）：
  - 静态服务 `assets/public` + `GET /api/session`、`GET /api/state`、`POST /api/state`（仅协作模式，demo 返回 403）；
  - `start/pushState/stop/getInfo` 四个方法，访客 POST 经 `stateReceived` 事件通知主机；
  - 线程安全（volatile + synchronized），内网 IP 遍历 NetworkInterface 自动获取。
- **同步协议**：整份 `PersistedAppState` JSON + 单调递增 rev，Last-Write-Wins；访客 1s 轮询 `/api/session` 比对 rev 增量拉取。
- **主机侧**：快照变化即 `pushState`；`stateReceived` 经 `normalizePersistedState` 校验后注入 UI，`applyingRemoteRef` 防回环。
- **访客侧**：启动探测 `/api/session`（2s 超时，404 即普通 Web 端）；协作模式本地变更 POST 回主机（内容去重防自回环）；访客不写本机 localStorage。
- `storage.ts` 把状态校验/迁移逻辑抽为 `normalizePersistedState` 导出复用，`loadState` 行为不变。
